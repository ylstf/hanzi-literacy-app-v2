# 天台山游学家庭账户设计

## 已确认的业务规则

- 一个家庭使用一个手机号注册和登录。
- 一个家庭账户可以关联一至多位已缴费学员。
- 每位学员拥有独立且永久的连续编号，例如 `天台001号`、`天台002号`。
- 编号只在学员首次通过报名验证并创建档案时分配一次；删除、退出或退款后不回收旧编号。
- 家庭只需完成一次任务，完成状态同步到该家庭账户下的全部有效学员。
- 换手机或电脑登录后，家庭成员、编号和任务进度保持不变。

## 数据结构

### families（家庭账户）

- `id`：家庭账户唯一 ID
- `phone`：登录手机号（唯一）
- `createdAt`：注册时间
- `status`：账户状态

### learners（学员档案）

- `id`：学员档案唯一 ID
- `familyId`：所属家庭账户 ID
- `name`：学员姓名
- `serialNumber`：全局连续数字
- `displayCode`：展示编号，例如 `天台001号`
- `status`：报名有效状态
- `createdAt`：档案创建时间

### familyProgress（家庭共同进度）

- `familyId`：家庭账户 ID
- `missionId`：任务 ID
- `completedAt`：完成时间
- `answerRecord`：必要的答题记录

### invitations（缴费验证）

- `code`：一次性家庭邀请码
- `allowedLearners`：该家庭已缴费人数（1、2、3……）
- `usedByFamilyId`：使用该邀请码的家庭账户
- `status`：未使用、已使用、停用

## 安全与编号规则

- 手机验证码、邀请码验证和编号分配全部在云端完成，浏览器不能自行生成编号。
- 创建学员和分配编号必须由同一个云函数事务完成，避免两位学员拿到重复编号。
- 任务开放状态由云端配置；未开放任务只显示“剧情封印中”，不能进入详情。
- 当前本地随机编号和公共活动码 `TT2026` 仅在迁移期保留，正式账户系统上线后停用。

## 上线顺序

1. 创建 CloudBase 环境并启用手机号验证码登录。
2. 建立数据库集合和连续编号云函数。
3. 建立家庭注册、添加学员和登录页面。
4. 把任务进度从本机存储迁移到家庭账户。
5. 在测试域名完成多人同时注册、换设备登录和任务同步测试。
6. 验收后合并到正式官网。
