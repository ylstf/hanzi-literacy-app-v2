# 识字闯关星球

这是第二版识字量测试网页应用，不覆盖第一版 `hanzi-literacy-app`。

## 主要变化

- 面向家长分享版：首页文案改为使用说明，算法说明收进“怎么测？”。
- 首次打开需要输入孩子昵称，不再默认直接进入“小朋友”。
- 品牌露出：儿童识字量测评工具 · 书法郭爸团队出品。
- 视觉方向改为“温暖闯关 + 儿童测评工具”。
- 快速估算从 60 题升级为 200 题。
- 2500 字按 100 字一组，分为 25 组。
- 每组完成后显示小结。
- 快速估算、分组闯关和“不认识的字”重测都支持撤回最近 10 次判断。
- 支持多孩子管理：昵称切换，每个孩子独立保存进度。
- 支持“不认识的字”：汇总“不认识”的字，可单字重测或全部重测。
- 支持生成测评报告图片，报告中包含识字量小结和网站二维码。
- 刷新页面后会尽量恢复到上次所在功能页，测评进度仍保存在本机浏览器。
- 反馈入口：问题和建议可添加微信 `ylstf08`。
- 加入轻量音效，可开关。
- 使用独立本机存储 key：`hanzi-literacy-v2`，不会清空旧版数据。

## 使用

直接打开 `index.html`。

## 测试规则

孩子看单字并读出来，家长点击“认识 / 不认识”。测试页不显示拼音、组词、图片或例句。

## 快速估算逻辑

当前字库共 2500 字，按字库顺序粗分为 10 个难度层，每层约 250 字。

快速估算模式会从较容易层开始抽样：

- 答“认识”后，下一题更倾向进入更高难度层。
- 答“不认识”后，下一题更倾向回到更低难度层。
- 200 题结束后，分别计算各难度层的认识率。
- 每层按约 250 字折算，最后合计为估算识字量。

结果页给出的是抽样估算值，不是逐字精确统计。200 题比原 60 题更稳定，因为每个难度层更容易获得足够样本。

快速估算撤回会沿原路径返回：撤回几个字，就按原来的字序重新出现，避免重新随机造成误解。

## 分享部署

这是纯静态网页，不需要后端。可以把整个 `hanzi-literacy-app-v2` 目录上传到腾讯云 EdgeOne Pages、腾讯云 COS、阿里云 OSS 或其他静态托管服务。

需要上传的文件包括：

- `index.html`
- `styles.css`
- `app.js`
- `data/hanzi.js`

当前版本的数据保存在访问者自己的浏览器本地存储里。分享给家长使用时，每个家庭的数据只在自己的设备上，不会自动同步到你的服务器。

更完整的上线、备案、腾讯云和阿里云部署步骤见 [docs/deployment-guide.md](docs/deployment-guide.md)。
